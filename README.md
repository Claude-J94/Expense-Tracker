# 💸 Expense Tracker (Python + PyQt5)

A simple desktop GUI application to track your daily expenses. You can add, modify, delete, and view your spending — with category-wise summaries, all stored in a CSV file.

## 🚀 Features

- ✅ Add new expenses (Date, Category, Amount, Description)
- ✏️ Modify existing entries
- 🗑️ Delete selected expenses
- 📊 Show summary (total + per-category)
- 💾 CSV-based data storage (no database needed)

---

## 🧰 Built With

- Python 3.x
- [PyQt5](https://pypi.org/project/PyQt5/)
- CSV for data storage
